LEVEL UP QUEST - install guide

1. Put this whole folder online (any free static host works):
   - Netlify Drop: go to app.netlify.com/drop and drag this folder in.
   - or GitHub Pages: upload the folder to a repository and turn on Pages.
2. Open the link on your phone.
   - Android (Chrome): menu > Install app.
   - iPhone (Safari): Share > Add to Home Screen.
3. It opens like an app and works offline after the first visit.

Progress is saved on each device. Syncing between devices and friends comes with the multiplayer step.
